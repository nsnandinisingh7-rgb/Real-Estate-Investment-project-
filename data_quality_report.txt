7. TARGET VARIABLES (derived using stated assumptions)
======================================================================
The dataset has NO appreciation rate and NO future price, so both targets are
created from domain rules. Document these assumptions in your report.

Future_Price_5Y_Lakhs = Price * (1 + g)^5,  g = 5% + up to 4% (infrastructure) - up to 1% (age)
Good_Investment = 1 if >= 3 of 4 rules pass: price <= city median per sqft, infra >= median, growth >= median, age <= 20 yrs
Class balance: Good = 39.2%, Not good = 60.8%

!! LEAKAGE WARNING !!
Good_Investment is built from PPSF_vs_City_Median, Infrastructure_Score,
Annual_Growth_Rate and Age_of_Property. If you feed those into the classifier,
accuracy will be ~100% and meaningless. They are excluded from CLASSIFICATION
features in the model-ready file. Likewise Annual_Growth_Rate/Appreciation_Pct_5Y
are excluded from REGRESSION features.
